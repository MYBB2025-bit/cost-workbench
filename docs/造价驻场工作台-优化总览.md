# 造价驻场工作台 · 竞品参照优化总览

参照 `edm.cqem.net` 企业工作台与项目级 workbench 页面，对单文件离线 HTML 工作台累计完成 5 项竞品参照功能升级，并新增「最终资料台账」模块。
所有改动向后兼容真实 184MB 业务数据，沿用 `cost-workbench.html` + `data/` 架构，EXE 同目录替换即生效，无需重打包。

## 已落地功能

### ① 核价库升级为「询价与核价数据库」
- 新增 `category`(分类) / `inquiryPrice`(询价单价) / `validUntil`(有效期) 字段
- 分类筛选 + 每行编辑 + 「价格库速览」按材料+规格聚合（记录数/最新核价/价格区间/最新供应商）
- CSV 导入导出扩列并兼容旧 11 列

### ② 风险中心 + 预警中心
- 风险中心：聚合 今日待办/结算/收方签证/对量争议 中标记风险项，一键跳原模块处理
- 预警中心：截止日期逾期·临期（可配提前天数）+ 进度款超概·超预算，按级别排序、可保存规则
- 修复历史缺陷：`page-risk`/`page-warning` 原被错误嵌套于 `page-projects` 内，导致即使激活也不显示；已改为平级顶层 section

### ③ 数据统计驾驶舱（新模块「数据统计驾驶舱」）
- 项目总台账：估算/概算/预算合计 + 逐项目明细（万元）
- 结算汇总：事项数 / 送审总额 / 已办·在办·审核中 / 风险项 + 办结率进度条
- 进度款收支看板：概算合计 / 累计已付 / 余额 / 支付比例 / 超概·超预算节点 + 比例进度条
- 模块数据速览：待办 / 收方签证 / 对量争议 / 核价 / 联系人 / 风险项

### ④ 工作台首页聚合 + 消息中心
- 首页（今日待办）升级为综合工作台：总览 KPI + 风险速览 + 预警速览 + 最近资料，均可跳转对应模块
- 新增「消息中心」模块：风险 + 预警 + 最近资料 合并为统一通知列表（风险红 / 预警分级 / 资料灰）

### ⑤ 项目阶段 + 个人工作台（参照项目级 workbench 页面）
- **项目阶段**：项目新增 `phase` 字段（启动及策划 / 施工前准备 / 实施 / 竣工 / 归档 / 关闭）；项目清单增加「阶段」列（tag 显示）+「项目阶段分布」卡片（各阶段计数），旧项目缺字段显示「未设置」
- **个人工作台**：原「消息中心」升级为多 Tab 个人工作中心——工作待办 / 待我处理（在办·审核中结算 + 未审核通过收方签证 + 未解决争议）/ 已办 / 风险 / 预警 / 成果文件，每个 Tab 带计数徽标与「前往」跳转（主色沿用竞品 #3A61C4）

### ⑥ 最终资料台账（资料库新能力）
- **自动汇总**：只读汇总所有审批状态为最终形态的业务资料，不移动原数据
  - 结算 `auditStatus` ∈ {已办/已办结/办结/完成/通过/审核通过/已结}
  - 收方签证 `reviewStatus === 审核通过`
  - 对量争议 `status === 已解决`
  - 用印记录 `status ∈ {已通过/已盖章}`
  - 项目部内业 `status === 已办`
  - 工作联系函 `sealed === true`
  - 资料库 checklist 项 `checked === true`
- **在线查看（参照 WPS）**：弹窗大表格，支持搜索、按资料类别筛选、查看原始字段详情、一键跳转来源模块
- **导出下载**：
  - **Excel**：`.xls`（HTML table，Excel/WPS 可直接打开）
  - **Word**：`.doc`（HTML，Word/WPS 可直接打开）
  - **PDF**：打开可打印页面并调用系统打印 → 打印为 PDF
